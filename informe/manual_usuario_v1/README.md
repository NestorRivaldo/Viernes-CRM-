## 🚀 Cómo Abrir y Usar el Manual

1. Haz doble clic en **`index.html`** (o `manual_usuario_v1.html`) para abrirlo en cualquier navegador web moderno (Chrome, Edge, Firefox).
2. No requiere conexión a internet ni servidores activos: todos los estilos, fuentes, tablas y capturas están embebidos y enlazados localmente.
3. Para exportar a **PDF**: presiona `Ctrl + P` en el navegador, selecciona destino *"Guardar como PDF"* con gráficos de fondo habilitados. El manual incluye reglas CSS `@media print` que formatean el documento a fondo blanco con cortes limpios de página.

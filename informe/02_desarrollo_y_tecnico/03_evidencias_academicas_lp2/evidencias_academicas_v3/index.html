Hallazgos que cambian la interpretación

Oracle tiene cinco tablas CRM no mapeadas y siete columnas adicionales en tablas mapeadas. Las siete tablas puente sí tienen FK físicas en el catálogo, aunque JPA use IDs escalares. La documentación anterior que deducía “sin FK física” a partir del código no debe usarse como prueba del esquema.

La ejecución Maven previa de 291 tests incluyó contextLoads con conexión Oracle y perfil dev/keycloak. Como dev tiene ddl-auto:update, no se puede certificar esa ejecución como solo lectura ni asegurar que no emitiera DDL. No se repitió. Las nuevas extracciones de metadatos sí se limitaron a transacciones READ ONLY, SELECT y ROLLBACK.

Cómo utilizar la entrega

Abra las secciones HTML para copiar texto y tablas a Word. Informe HTML consolidado y texto plano consolidado. Los CSV son editables y cada UML/ERD incluye PlantUML; los procesos se abren como .bpmn en un modelador compatible. Los SVG se conservan vectoriales para ampliar sin perder legibilidad. No escale los diagramas grandes a una sola página A4 sin dividirlos.

# Manual de Usuario - Viernes CRM V2.0

Este directorio (**V2**) contiene el paquete completo y actualizado del **Manual de Usuario de Viernes CRM (Versión 2.0)**, con todas las capturas actualizadas a la interfaz moderna basada en diálogos modales (*ClienteDialog*, *OportunidadDialog*, etc.).

---

## 📁 Estructura del Directorio V2

* **`index.html`** / **`manual_usuario_v2.html`**:
  Manual completo e interactivo que incluye:
  - 20 secciones operativas detalladas paso a paso.
  - Tabla de contenidos interactiva fija (TOC).
  - **28 capturas de pantalla reales** en alta definición de la versión actual V2.
  - Vistas de los formularios modales modernos (Registro y edición de clientes con RENIEC/SUNAT, Oportunidades, Leads, Actividades, Propuestas, etc.).
  - Matriz de permisos por rol (ADMIN, JEFE, VENDEDOR).
  - Reglas de impresión y exportación limpia a PDF (`Ctrl + P`).

## 🚀 Uso Rápido
- Haz doble clic en **`index.html`** para abrir el manual directamente en tu navegador.
- Para generar el PDF: presiona `Ctrl + P`, selecciona *Guardar como PDF* con *Gráficos en segundo plano* activados.

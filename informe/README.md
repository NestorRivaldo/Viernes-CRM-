# 📚 Centro de Documentación e Informes — Viernes CRM V1

Este directorio centraliza toda la documentación técnica, manuales de usuario, evidencias académicas y guías de evaluación del sistema **Viernes CRM**, clasificado de manera clara y profesional en tres niveles:

---

## 🗂️ Estructura de Carpetas

```text
informe/
│
├── 01_nuevo_y_vigente/             # Documentación vigente, final y guías oficiales
│   ├── 02_simulador_examen_actividades/ # Simuladores interactivos y test de código
│   ├── 03_manual_usuario_v2/       # Manual interactivo V2 con capturas de pantalla
│   ├── 04_guias_sustentacion_y_pitch/ # Guía de sustentación, pitch de 5 min y patrones
│   └── 05_informes_sistema_oficiales/ # Informes técnicos oficiales de arquitectura
│
├── 02_desarrollo_y_tecnico/        # Especificaciones técnicas, C4 y evidencias LP2
│   ├── 01_arquitectura_c4_nivel3/  # Diagramas C4 Modelo Nivel 3 (Componentes)
│   ├── 02_analisis_dominio_y_patrones/ # DDD, GRASP, GoF, PL/SQL Oracle y auditorías
│   ├── 03_evidencias_academicas_lp2/ # Criterios de aceptación, BPMN, UML y pruebas
│   └── 04_guias_tecnicas_keycloak/ # Guías de configuración OIDC y Keycloak
│
├── 03_antiguo_e_historico/         # Versiones anteriores, borradores y backups
│   ├── 01_versiones_desactualizadas/ # Informes preliminares de sprints anteriores
│   ├── 02_manual_usuario_v1_legacy/ # Manual V1 y capturas históricas
│   └── 03_backups_comprimidos_zip/  # Archivos comprimidos de respaldo
│
└── index.html                      # Portal web interactivo central con buscador
```

## 🚀 Acceso Rápido desde el Navegador

Para navegar de forma visual por todos los informes, simplemente abre en tu navegador:

👉 **[`index.html`](index.html)**

Incluye:
* **Buscador en tiempo real**: Encuentra cualquier documento por palabra clave o etiqueta.
* **Filtros por categoría**: `[Todos]`, `[Nuevo y Vigente]`, `[Desarrollo y Técnico]`, `[Histórico]`.
* **Enlaces funcionales**: Rutas relativas probadas y operativas sin enlaces rotos.

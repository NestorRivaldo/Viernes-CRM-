⚙️ VIERNES CRM V1 · GUÍA MULTI-PC

Activación y Despliegue en Otra Computadora

Instrucciones verificadas para levantar el sistema completo (Oracle 23c, Keycloak 25, Backend Spring Boot y Frontend Angular) en cualquier máquina con Windows.

⚡ Modo Automático con 1 Clic (Recomendado)

El proyecto incluye un lanzador universal inteligente que detecta dependencias, inicia Docker, espera los servicios y levanta las consolas automáticamente.

PASO 1

Tener Docker Desktop abierto

En la otra PC, abre el programa Docker Desktop y asegúrate de que el ícono de la ballena en la barra de tareas esté en verde (Engine running).

PASO 2

Ejecutar el Lanzador

Entra a la carpeta del proyecto en la otra PC y simplemente haz doble clic en:

Archivo ejecutable 
activar-sistema.bat

(También puedes ejecutarlo en PowerShell escribiendo .\activar-sistema.ps1).

PASO 3

¿Qué hace el activador automáticamente?

  • Detecta automáticamente Java 21 en cualquier carpeta de Windows (Eclipse Temurin, Microsoft OpenJDK, Oracle, etc.).
  • Verifica Node.js y npm.
  • Inicia Oracle Database 23c (puerto 1521) y Keycloak 25 (puerto 8180).
  • Espera a que Oracle esté saludable (healthy).
  • Si la PC es nueva: Detecta si la base de datos está vacía y corre automáticamente ejecutar_todo.sql para crear todas las tablas y usuarios demo de BOM_VENTAS.
  • Inicia el Backend Spring Boot en el puerto 8080 en su propia consola.
  • Verifica si falta node_modules e instala con npm install si es necesario.
  • Inicia el Frontend Angular en el puerto 4200 y abre el navegador automáticamente.

🛠️ Modo Manual (Orden Estricto de 3 Ventanas de CMD)

Si deseas levantar cada componente de forma individual, abre 3 terminales en este orden estricto:

VENTANA 1: DOCKER Y BASE DE DATOS

Levantar Contenedores de Oracle y Keycloak

Abre un CMD en la carpeta raíz del proyecto:

CMD / PowerShell — Ventana 1 
:: 1. Ir a la carpeta raíz del proyecto
cd /d C:\ruta\a\tu\proyecto\Viernes

:: 2. Levantar Oracle 23c (puerto 1521)
docker compose -f "base de datos\compose-dev.yml" up -d

:: 3. Levantar Keycloak 25 (puerto 8180)
docker compose -f compose-keycloak.yml up -d

⚠️ Si es la primera vez que se ejecuta en esa PC:

Carga todas las tablas y datos demo en Oracle ejecutando este comando:

CMD — Inicialización de BD 
type "base de datos\ejecutar_todo.sql" | docker exec -i viernes-oracle sqlplus -s system/123456@//localhost:1521/FREEPDB1
VENTANA 2: BACKEND (SPRING BOOT)

Arrancar Servidor REST en Puerto 8080

Abre una segunda ventana de CMD y déjala abierta:

CMD — Ventana 2 
cd /d C:\ruta\a\tu\proyecto\Viernes\viernes-backend
mvnw.cmd spring-boot:run

✓ Espera a ver: Started ViernesApplication in ... seconds y Tomcat started on port 8080.

VENTANA 3: FRONTEND (ANGULAR)

Arrancar Aplicación SPA en Puerto 4200

Abre una tercera ventana de CMD y déjala abierta:

CMD — Ventana 3 
cd /d C:\ruta\a\tu\proyecto\Viernes\viernes-frontend
:: Instalar librerías (solo primera vez)
npm install

:: Iniciar servidor Angular
npm start

✓ Espera a ver: Application bundle generation complete y Watch mode enabled.

🔍 Solución a Problemas Comunes en Otra PC

Síntoma / Error Causa Solución Inmediata
No se encontró Java 21 Java no está instalado o no está en el PATH. Descarga OpenJDK 21 desde adoptium.net y marca la casilla "Set JAVA_HOME".
Docker daemon is not running Docker Desktop está cerrado. Abre Docker Desktop desde el menú inicio y espera 20 segundos hasta que el ícono esté en verde.
Port 1521 is already in use Hay otro Oracle XE local corriendo nativamente. En CMD como Admin: net stop OracleServiceXE o detener el servicio local de Oracle.
Error al cargar clientes / Error 500 La base de datos se levantó limpia sin tablas. Ejecuta: type "base de datos\ejecutar_todo.sql" | docker exec -i viernes-oracle sqlplus -s system/123456@//localhost:1521/FREEPDB1
Error de puerto 8080 en uso Ya hay otro proceso usando el puerto 8080. En CMD: netstat -ano | findstr :8080 y luego termina el proceso con taskkill /PID <PID> /F.
